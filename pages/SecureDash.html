SecureDash

Résumé

SecureDash is a full Security Operations Center (SOC) platform built to detect, investigate, and respond to web application attacks in real time. It combines JWT authentication with 2FA (TOTP), role-based access control (Admin / Analyst / Auditor), and centralized monitoring through Wazuh integration. The platform automatically detects threats such as SQL injection, XSS, SSRF, and SSH brute-force attempts, and enables active response through automatic/manual IP blocking and network isolation (via iptables). It also features AI-powered alert analysis (Mistral AI), a built-in remediation knowledge base mapped to MITRE ATT&CK techniques, full audit logging, and automated OWASP Top 10 / ISO 27001 compliance reporting. Developed as part of a Master's thesis in Cybersecurity in collaboration with Djezzy, SecureDash raised a deliberately vulnerable test platform's OWASP Top 10 compliance score from 45% to 9/10 controls passed.
